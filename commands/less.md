# less：你每天都在用，但可能只用到了 10% 的功能

> `less` 是 Linux 上最常用的分页查看器。`less file.log` 然后上下翻——这是大多数人的用法。但 less 的真正威力在它的快捷键——搜索、标记、跳转、管道、多文件切换，它几乎是一个嵌入终端的文本浏览器。

## 一句话定义

**less = more 的反义词。** more 只能往前翻，less 可以前后翻。"less is more"——既是命名梗，也是事实：功能更多，但更灵活。

## 核心快捷键——按场景分组

### 导航

| 按键 | 功能 |
|------|------|
| `j` / `↓` / `Enter` | 下一行 |
| `k` / `↑` | 上一行 |
| `f` / `Space` | 下一页（forward） |
| `b` | 上一页（backward） |
| `d` / `Ctrl+D` | 下半页 |
| `u` / `Ctrl+U` | 上半页 |
| `g` | 跳到第一行 |
| `G` | 跳到最后一行 |
| `100g` | 跳到第 100 行 |

### 搜索

| 按键 | 功能 |
|------|------|
| `/pattern` | 向下搜索 |
| `?pattern` | 向上搜索 |
| `n` | 下一个匹配 |
| `N` | 上一个匹配 |
| `&pattern` | 只显示匹配的行（过滤器！） |
| `ESC u` | 关闭过滤器，回到完整视图 |

> 💡 **`&` 过滤器是 less 的隐藏大招。** `&ERROR` 让整个文件只显示含 ERROR 的行，不会丢失位置也不会改变文件。退出过滤器用 `ESC u`。

### 标记和跳转

| 按键 | 功能 |
|------|------|
| `m a` | 在当前行设标记 a |
| `' a` | 跳回标记 a |
| `''` | 跳回刚才的位置（两个单引号） |

> 💡 看一个超大日志，你想来回对比两处内容——`m a` 在第一处，翻到第二处，用 `' a` 跳回来，`''` 跳回去。

### 文件操作

| 按键 | 功能 |
|------|------|
| `:e file` | 打开另一个文件 |
| `:n` | 下一个文件（多文件浏览时） |
| `:p` | 上一个文件 |
| `q` | 退出 |
| `ZZ` | 如果文件被修改则重读 |

### 模式切换

| 按键 | 功能 |
|------|------|
| `F` | 进入 tail -f 模式（实时跟踪文件尾，效果等同于 tail -f） |
| `Ctrl+C` | 退出跟踪模式，回到正常模式 |
| `v` | 用默认编辑器（$EDITOR）打开当前文件 |
| `h` | 显示帮助（所有快捷键一览） |

> 💡 **`F`（大写）是 less 最被低估的功能。** 你在排查日志，先 `less` 翻到文件末尾看最近的错误，然后按 `F` 进入实时跟踪模式——不需要退出 less 再敲 `tail -f`。`Ctrl+C` 回到正常浏览。

## 命令行选项

```bash
# -N：显示行号
less -N file.log

# -i：搜索忽略大小写
less -i file.log

# -S：不自动换行（长行可以横向滚动 → ←）
less -S access.log

# -R：保留 ANSI 颜色转义（配合 grep --color 使用）
grep --color ERROR file.log | less -R

# +：打开文件后直接执行命令
less +100 file.log        # 跳到第 100 行
less +/ERROR file.log     # 跳到第一个 ERROR
less +F file.log          # 进入 tail -f 模式
```

> 💡 `less +/ERROR file.log` 是日常最高效组合——打开文件直接定位到第一个 ERROR。

## 踩坑清单

- **坑一：`less` 退出后屏幕不清空** → 默认行为（和 more 的区别之一）。想退出清屏用 `less -X` 的反选：不设置此选项时默认不清屏。
- **坑二：`less` 管道使用时不显示文件名和进度** → `cat file | less` 时 less 不显示当前位置（因为它不知道文件总行数）。直接 `less file` 才有进度百分比。
- **坑三：搜索默认区分大小写** → 加 `-i` 或在 less 里按 `-i` 再 `/search`。

## 什么时候该换工具

| 场景 | 用什么 | 为什么 |
|------|--------|--------|
| 浏览/搜索文件 | less | 最好用的分页器 |
| 实时跟踪日志 | `tail -f` | 不做交互浏览时更轻量 |
| 编辑文件 | vim/nano | less 只是浏览器，不能编辑（除了 `v` 快捷键跳转） |
| 语法高亮查看 | `bat` | cat 的现代替代，也支持分页 |
| 超大 JSON 浏览 | `jq . \| less` | jq 格式化后再用 less 浏览 |

---

> **核心观点：** less 不需要"学"——它只有 `j/k` 上下、`/` 搜索、`q` 退出三个必须知道的键。但你今天应该试一下这个组合：**`less +/ERROR file.log`**（打开即定位），然后按 **`&FATAL`**（过滤只显示 FATAL 行），按 **`F`**（进入实时跟踪）。这三个按键链让你的日志排查从"上下翻找"变成"精确定位+实时监控"。
